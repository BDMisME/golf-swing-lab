# PRD — Golf Swing Lab 產品需求規格書

## 1. 產品願景與目標受眾
- **核心受眾**：在練習場固定將 iPhone 架設於球員身後（Down-the-Line, DTL）連續錄影 10–30 分鐘的個人高爾夫球友（預設右打，資料模型完整支援左打 `left`/`right`）。
- **解決痛點**：
  1. 練習場錄下 20 分鐘影片含 30–60 次揮桿與空揮，手動在手機相簿拉時間軸找球極為耗時。
  2. 市面軟體常宣稱不切實際的 2D 測速或假球軌，缺乏誠實、可追溯時間碼與可解釋的動作穩定度檢核。
  3. 挑出當日姿勢最穩定或最適合社群分享的 2–3 球並剪輯成 9:16 短片流程繁瑣。

## 2. 六大核心使用者旅程（U1–U6）
- **U1 大檔匯入與續傳**：支援單檔或多檔 `.MOV` / `.MP4`（H.264 / HEVC），透過 Multipart 直傳 S3/MinIO，支援單 Part 重試、中斷續傳與 SHA256 校驗。
- **U2 非同步背景處理**：上傳完成後由 Redis/RQ Worker 於背景執行 `probe → proxy → coarse_scan → fine_scan → scoring → report`，關閉瀏覽器不影響任務，重開可查看真實進度與重試。
- **U3 自動切球與時間軸校正**：自動偵測每次揮桿起迄（`start_ms`, `end_ms`）與原片時間碼，區分正式揮桿（`valid_swing`）、空揮（`practice_swing`）與低信心候選（`swing_candidate`）；支援手動新增、刪除、微調起迄邊界與標註擊球狀態。
- **U4 單球詳情、骨架與可解釋評分**：檢視單球短片、關鍵階段時間點（Address / Takeaway / Backswing / Top / Downswing / Impact Estimated / Follow-through / Finish）、Canvas 2D 骨架疊圖、分項指標與「怎麼算的？」計算依據；覆蓋率不足 `<70%` 時明確標示「無法可靠評分」。
- **U5 場次報告與精選排名**：彙整場次總球數、有效揮桿、待人工確認數、分項趨勢，以及四大排行榜（姿勢最佳、節奏最佳、收桿最佳、IG 視覺呈現最佳），並支援人工加入/排除與雙球同步對照。
- **U6 真實畫面 MP4 匯出**：支援單球或 2–3 球連續精選匯出，可選原始比例（`original`）或直式社群比例（`9:16`），保留真實畫面，絕不合成虛假飛行軌跡。

## 3. 誠信紅線（不可違反）
1. 禁止輸出或推論：飛行距離、球速、桿頭速度、擊球甜蜜點、精確桿面角、精確 3D 身體旋轉角、實際球路方向。
2. 擊球瞬間僅能標記為 `impact_estimated_ms`（附推定方法與信心度），無法確認有球時標記為 `strike_unknown`。
3. 動作總分與分項分數須揭露 `score_version`、輸入指標、權重與信心度。
4. 未設定 LLM API Key 時（`LLM_PROVIDER=none`），系統所有核心功能完全可用，且 AI 教練區塊清楚標示規則式分析與進階 LLM 尚未啟用，絕不偽造 AI 回應。
