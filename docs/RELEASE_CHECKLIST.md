# RELEASE_CHECKLIST.md — 上線前檢核清單

## 1. 功能與誠信檢核（P0 / P1）
- [ ] **身分與權限**：未登入請求 `/api/*` 100% 回傳 `401`；跨用戶存取 100% 回傳 `403`。
- [ ] **大檔上傳與續傳**：支援 `.MOV` / `.MP4`（H.264 / HEVC）分段上傳、單段失敗重試、完成校驗與中斷恢復。
- [ ] **真實時間碼**：使用 `ffprobe` 解析真實 PTS、旋轉方向與 VFR，不因長片產生時間軸嚴重偏移。
- [ ] **背景處理**：分析與匯出由背景佇列執行，重新整理或關閉瀏覽器分頁不中斷任務。
- [ ] **自動切球與手動校正**：可自動偵測多次揮桿與空揮，並於前端時間軸新增、刪除、微調起迄與標註擊球狀態。
- [ ] **無虛構指標**：UI 與 API 回應中絕無未經驗證之球速、桿頭速度、飛行距離、精確桿面角或假飛行軌跡。
- [ ] **可解釋評分**：每項分數皆附 `score_version`、公式、信心度与「怎麼算的？」明細；有效權重覆蓋率 `<70%` 時不輸出總分。
- [ ] **場次報告與雙球對照**：支援四大精選排名（姿勢、節奏、收桿、IG 視覺）與同場雙球同步對照播放。
- [ ] **MP4 匯出**：支援單球與 2–3 球合輯匯出（原始比例與 9:16），輸出檔案可於 Safari 正常播放。
- [ ] **LLM 無金鑰可用**：`LLM_PROVIDER=none` 時全系統正常運作並提供規則式教學建議，不發送外部請求。

## 2. 部署與外部驗證狀態
- [ ] Docker Compose 本機環境與 Dockerfiles 驗證通過。
- [ ] 真實 10–30 分鐘 iPhone DTL Golden Set（100+ 球）實測：若無外部真實長片樣本，維持標示 `NOT_VALIDATED`。
- [ ] Zeabur Staging / Production 遠端部署：若無 Zeabur 帳號與專案授權，維持標示 `EXTERNAL_BLOCKER`。
